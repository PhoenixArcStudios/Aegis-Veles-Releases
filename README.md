## 🚀 Overview

**Aegis Veles** is a robust, offline-first desktop application built for professional broadcast environments, live events, and production crews. It bridges the gap between traditional newsroom rundown management and high-performance dual-screen teleprompting, giving producers and talent a seamless, synchronized workflow.

Whether you are managing a complex multi-block broadcast or running text for a live stage production, Aegis Veles keeps your crew locked in step.

---

## ✨ Key Features

* **Dynamic Rundown Management:** Build and structure your show with fully customizable metadata columns (Talent, Cam, Graphics, etc.), block breaks, and automatic A/B/C segment lettering.
* **Advanced Script Markup Engine:** Easily format script elements using custom bracket tags (Headings, Speakers, Cues, and Directions) complete with customized color highlights and text scaling.
* **Live Dual-Screen Teleprompter:** Instantly sync your rundown scripts to a dedicated, full-screen prompter display with variable speed control, sub-pixel smooth scrolling, and screen mirroring support.
* **Bookmark Navigation:** Insert dynamic markers (`#bookmark#`) into scripts to effortlessly jump your prompter or preview screen on the fly.
* **Professional PDF Export & Printing:** Generate paginated, mathematically accurate US Letter printouts for both full show rundowns and individual talent scripts without ghost page overflow.
* **Rapid Editing Tools:** Streamline your workflow with native keyboard shortcuts (`Cmd/Ctrl + C/V/D`), double-click-to-edit actions, and right-click context menus.
* **Session Persistence & Templates:** Utilize automated background auto-saves, crash recovery prompts, and reusable show templates to spin up new productions instantly.

## 📦 Getting Started & Installation

1. Head over to the [Releases Page](https://github.com/PhoenixArcStudios/Aegis-Veles-Releases/releases) to download the latest installer for your operating system.
2. Run the installer and launch the application.
3. Upon first launch, the built-in **Quick Start Guide** will automatically walk you through the core features and shortcuts. 
4. Want to dive right in? We've bundled a complete **Sample Broadcast rundown** directly into the app—check your **Recent Shows** menu on the welcome screen to load it instantly!
